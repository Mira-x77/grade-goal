# Go Study! Presentations

This folder contains presentation materials for Go Study!

## Presentation 1: General Public

**Target Audience:** Students, parents, teachers  
**Purpose:** Showcase the app's tools and how they solve student problems  
**Theme:** Cartoon/Neo-brutalist with bright colors and thick borders  
**Duration:** 5-10 minutes

### Quick Start

#### Option 1: Auto-Generate with Python (Recommended)

1. Install Python from [python.org](https://www.python.org/downloads/)
2. Install the required package:
   ```bash
   pip install python-pptx
   ```
3. Run the generator:
   ```bash
   python scripts/create_presentation.py
   ```
4. Open `docs/presentations/Go-Study-Presentation-1-General-Public.pptx`

#### Option 2: Manual Creation in PowerPoint/Google Slides

See the complete slide content in the artifact or markdown file. Each slide includes:
- Exact text content
- Color codes
- Font sizes
- Layout instructions
- Design tips

### Design System

**Color Palette:**
- Background: `#EDEAE5` (Warm Canvas)
- Text: `#1A1A1A` (Ink Black)
- Yellow: `#F5C842` (Highlighter)
- Blue: `#0284C7` (Sky Blue)
- Red: `#EF4444` (Coral)
- Green: `#16A34A` (Success)
- Purple: `#9333EA`
- Gold: `#C9960C` (Premium)

**Typography:**
- Headings: Segoe UI Bold (28-72pt)
- Body: Segoe UI Regular (14-18pt)
- Icons: Emoji at 24-48pt

**Neo-Brutalist Cards:**
1. Rounded rectangle with 2.5-3pt black border
2. Duplicate for shadow, offset 5-8pt down-right
3. Fill shadow with black, send to back

### Slide Breakdown

1. **Title Slide** - Hook with app name and tagline
2. **The Problem** - 4 pain points students face
3. **The Solution** - How Go Study! addresses each problem
4. **Tool #1: Grade Calculator** - Calculate average instantly
5. **Tool #2: Score Strategizer** - Plan path to target grade
6. **Tool #3: Exam Library** - Access past papers offline
7. **Premium Features** - Unlimited access benefits
8. **Get Started** - 3-step onboarding flow
9. **Thank You** - Closing with contact info

### Tips for Presenting

- **Slide 1-2:** Hook with relatable student struggles
- **Slide 3-6:** Demo each tool with enthusiasm
- **Slide 7:** Emphasize affordability (1,500 FCFA/month)
- **Slide 8:** Clear call-to-action
- **Slide 9:** Open for questions
