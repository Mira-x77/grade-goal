MODULE 1 • CODING BASICS
THE CREATOR'S GUIDEBOOK
Ch 1: Coding Languages 101
What main programming languages are for and what they do
Coding is simply giving step-by-step instructions to a computer in a language it understands. Different coding
languages are designed for different specialized jobs!
Frontend vs. Backend Made Simple
FRONTEND (What You See)
Everything visible on your screen: buttons, colors, text,
animations, and responsive layouts.
HTML: The skeleton (text, headings, & layout structure).
CSS: The clothes & paint (colors, fonts, & flex
alignment).
JavaScript: The muscle (button clicks, popups, &
animations).
BACKEND (Behind the Scenes)
The hidden brain operating on remote servers to manage
accounts, passwords, and databases.
Python: Easy, popular backend & AI language.
Node.js / SQL: Handles server traffic & database user
records.
APIs: Bridges connecting Frontend requests to Backend
data.
💡BASIC DEFINITION • IDE: An IDE (Integrated Development Environment) is simply the code editor program where
programmers write and run code files! Examples: VS Code or Cursor.

Ch 2: Static vs. Functional Sites
Understanding the two main types of websites
Before building a web project or prompting AI, you need to know which type of website you are creating!
1. Static Websites (Digital Posters)
Show the exact same content to every visitor. They do not
save user logins or process custom live data.
Examples: Portfolios, restaurant menus, school blogs.
Built With: Simple HTML & CSS.
Benefit: Super fast & easy to build!
2. Functional / Dynamic Sites
Interactive web applications that change based on user
actions, save progress, or handle user accounts.
Examples: Scratch, YouTube, games, online stores.
Built With: JavaScript + Backend Database.
Benefit: Interactive & personalized!
Static vs Dynamic Feature Comparison
Feature
Static Websites
Dynamic / Functional Apps
User Logins
No user accounts
Full accounts & passwords
Data Storage
Fixed text in files
Saves to server database
Build Time
Minutes to hours
Days to weeks
💡BASIC DEFINITION • HTML:HTML (HyperText Markup Language) is the standard code structure used to place
headers, text, images, and buttons on web pages.

Ch 3 & 4: Intro to Vibe Coding & AI Prompting
Creating software by talking to AI in plain English
Vibe Coding means using modern AI tools (like ChatGPT, Claude, or Cursor) to write code for you while you guide
the project using plain English prompts!
What AI Needs from You (The 3 Key Requirements)
1. Clear Goal
Tell AI exactly what app to make (e.g.,
"Make a simple score counter web
page").
2. Target Tech
Specify the language (e.g., "Use
single-file HTML and Vanilla CSS").
3. Style & Features
Describe colors, layout, and button
behavior preferences.
The Simple 3-Step Prompt Formula
3-STEP PROMPT FORMULA
BEGINNER FRIENDLY
1. WHO AI IS: "You are an expert front-end web developer..."
2. WHAT TO BUILD: "Build a clean single-file HTML page for my game..."
3. SPECIAL RULES: "Use a dark blue background, big green action buttons, and keep the code simple."
⚡The Vibe Coding Secret: You don't need to memorize coding syntax anymore—just learn how to describe what you
want clearly!

Ch 5 & 6-7: Hardware /software
Essential safety rules and pre-flight checklist
🚨STRICT SECURITY RULES! What NEVER to share with AI:
• Passwords & PINs: Never paste real user passwords or logins.
• Private API Keys & Tokens: Secret keys to online services.
• Personal Data: Phone numbers, home addresses, or credit cards.
• Database Credentials: Secret database login credentials.
SAFE CODE EXAMPLE • ALWAYS SANITIZE
// WRONG (UNSAFE): const myApiKey = "sk_live_998877665544332211";
// CORRECT (SAFE): const myApiKey = "YOUR_API_KEY_HERE";
The Vibe Coding Pre-Flight Checklist
✅ Know whether you need a Static site or a Functional site.
✅ Decide your target tech stack (HTML, CSS, JS, Python).
✅ Open your IDE editor (VS Code or Cursor).
✅ Write clear prompts specifying goals and layout preferences.
✅NEVER share passwords or private API keys with AI!
✅ Test generated code in your web browser step-by-step.

Ch 8: Scratch Controls & Block Basics
Understanding sprites, stage coordinates, and visual code blocks
Scratch is MIT's visual block programming platform. Instead of typing complex syntax, you snap color-coded blocks
together like LEGO bricks!
Key Scratch Concepts
1. Sprite
Characters or objects on stage (Cat,
Dino, Shark, Basket).
2. Stage
The game screen background grid
(480 wide x 360 high).
3. Script
Connected stack of blocks telling a
sprite what to do!
Essential Scratch Block Types

💡Stage Coordinates: The center of the Scratch stage is (X: 0, Y: 0). X goes from -240 (Left) to +240 (Right). Y goes
from -180 (Bottom) to +180 (Top).

Ch 16 & 17: Cutting Clips & Transitions
Trimming boring parts, splitting scenes, and adding smooth transitions
Step-by-Step Cutting Protocol in CapCut
1. Import Footage: Drag your recorded video clips into CapCut's media panel.
2. Drag to Timeline: Place your videos onto Main Video Track 1.
3. Split / Cut: Move playhead line to cut spot, and click Split (Razor) tool (or press Ctrl + B).
4. Delete Bad Parts: Select unwanted middle clip segment and press Delete!
5. Automatic Join: CapCut automatically snaps remaining clips together seamlessly!
Popular CapCut Transitions
Dissolve / Fade
Smoothly blends Clip A into Clip B for
time passes or calm cuts.
Camera Push / Zoom
Energetic zoom in/out effect great
for tech reveals or action moments!
Blur Wipe
Wipes left or right with a quick
motion blur effect.

Ch 18: Adding Memes & Overlays
Using Green Screen memes, funny reactions, and picture-in-picture
Adding funny Meme Clips (laughing reactions, vine booms, green screen popups) makes tech and gaming videos
super entertaining!
Using Green Screen Cutout in CapCut
1. Drag your Green Screen Meme Clip onto Video Track 2 (above your main video).
2. Select the meme clip on timeline -> Go to Cutout Tab in right inspector panel.
3. Check Chroma Key -> Use Color Picker dropper to pick green background color.
4. Increase Strength slider until green background disappears completely!
💡Pro Meme Tip: Pair funny meme visual popups with matching sound effects (e.g. pop sound or funny laugh) for
maximum humor!

Auto-subtitles, background music balance, and export settings
1-Click Auto-Captions
Go to Text Tab -> Auto Captions -> Create. CapCut's AI
instantly transcribes your voice track into synced subtitles!
Styling Viral Captions
Use bold modern fonts (Montserrat/Impact), add yellow
highlight text color, and subtle black text outline shadow.
Proper Audio Volume Balance
Voiceover / Speech Track
Keep loud & clear (Volume set around 0 dB to +2 dB).
Background Music Track
Lower volume significantly (set around -15 dB to -20 dB)
so voice stays easy to hear.

THE CREATOR'S GUIDEBOOK
Ch 22: What is a Robot? (Casual View)
Surface-level knowledge about smart machines without scary math
A Robot is simply a machine that can automatically sense its environment, think using code, and perform a physical
action!
The 3 Parts Every Robot Has
1. SENSORS (Eyes & Ears)
Detect things like distance, light,
touch, or sound around the robot.
2. THE BRAIN (Microcontroller)
Small chip running code that decides
what action to take.
3. MOTORS & LIGHTS (Hands
& Legs)
Spin wheels, move arm joints, blink
LEDs, or play sounds.
💡Casual Robotics Tip: Robotics is just hardware + code working together!
