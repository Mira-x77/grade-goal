🔧 Reset ScoreTarget App Cache

Problem

Your app shows only 8 papers because 55 papers are marked as "downloaded" in the cache and being hidden.

Solution

Clear all cached data to reset the app to a fresh state.

Step 1: Clear All Caches

Step 2: Reload App

Step 3: Check Status

What Gets Cleared

  • ✅ Downloaded papers list (frees up all 55 "downloaded" papers)
  • ✅ Saved filter state (Class Level, Subject, Year filters)
  • ✅ Cached paper data
  • ✅ IndexedDB database
  • ✅ All localStorage for this app

Manual Steps (if buttons don't work)

// Open browser console (F12) and run:

// 1. Clear localStorage
localStorage.clear();

// 2. Clear IndexedDB
indexedDB.deleteDatabase('exam-library-cache');

// 3. Clear service worker cache
caches.keys().then(keys => {
    keys.forEach(key => caches.delete(key));
});

// 4. Reload
location.reload();
