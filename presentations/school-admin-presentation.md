## 🔐 How It Works (Code System)

### Simple 3-Step Process

1. **School Purchases Codes**
   - Bulk codes delivered digitally
   - Each code: 12 characters (XXXX-XXXX-XXXX)
   - Valid for specified duration

2. **School Sells to Students**
   - Via registry/administration office
   - Cash or mobile money payment
   - Instant code delivery

3. **Student Activates**
   - Opens app → Settings → Enter code
   - Premium unlocked immediately
   - Works on 2 devices

### Admin Dashboard
- Track code activation rates
- Monitor student usage
- Request new code batches
- View revenue reports
