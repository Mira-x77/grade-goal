## 📱 Install on iPhone

### Option 1: Use a Mac
1. Copy entire `grade-goal` folder to Mac
2. Open Terminal: `cd /path/to/grade-goal`
3. Run: `npx cap open ios`
4. In Xcode, click Play ▶️
5. App installs on iPhone/simulator

### Option 2: Cloud Build (No Mac!)
1. Go to https://codemagic.io
2. Sign up and connect your GitHub
3. Build iOS app in cloud
4. Download .ipa file
5. Install using AltStore or TestFlight

## 🆘 Troubleshooting

### Android Install Issues
- Enable "Install unknown apps" in Settings
- Check storage space (needs ~20 MB)
- Uninstall old version first if upgrading

### iOS Build Issues
- Mac requires Xcode from App Store (free)
- Need CocoaPods: `sudo gem install cocoapods`
- For cloud build, check build logs in service dashboard
